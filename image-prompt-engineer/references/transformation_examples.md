## Transformation Pattern Summary

**Nano Banana Pattern:**
Subject + Face Details + Lighting + Camera + Style

**FLUX Pattern:**
Subject + Composition + Mood + Style + Variant Selection

**Recraft V3 Pattern:**
Subject + Text (quoted) + Typography + Colors + Vector

**SeeDream V4 Pattern:**
Subject + Resolution + Details + Textures + Production Context

**SD 3.5 Large Pattern:**
Subject + Text (if present) + Elements + Spatial Relations + Composition
